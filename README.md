# Satpam-Lozy

Smart Security Management System — Frontend Web Application untuk Petugas Keamanan (Satpam) & Admin Monitoring.

## 🚀 Fitur Utama
- **Autentikasi & Sesi Mandiri:** Login petugas & admin dengan proteksi single-device.
- **Buku Tamu Digital:** Check-in/check-out tamu, pencatatan nopol, dan foto KTP.
- **Live Patroli Scanner (60 FPS):** Pemindai QR Checkpoint hardware-accelerated dengan tombol senter (torch) untuk patroli malam hari (18:00 - 06:00).
- **Logistik & Gate Pass:** Manajemen muat barang dan surat jalan truk (Area Packing).
- **Paket & Kunci Ruangan:** Serah terima paket ekspedisi & peminjaman kunci (Kantor Utama).
- **Pelaporan Insiden & Darurat:** Auto-alert prioritas insiden.
- **Dashboard KPI Super Admin:** Pemantauan kepatuhan GPS, leaderboard poin, dan statistik real-time.

## 📁 Struktur Halaman
- `index.html` — Halaman Login
- `app.html` — Portal Operasional Satpam
- `admin.html` — Dashboard KPI Super Admin
- `scanner.html` — Live Barcode/QR Scanner HD
- `print-qr.html` — Lembar Cetak QR Checkpoint
- `api-config.js` — Penghubung REST API ke Google Apps Script
